# Alarm sound assets — provenance + license record

Per ADR 0009 Decision A: 5 alarm tones shipped to all platforms, stored once in `src/assets/alarm-sounds/`, used unchanged by the Electron desktop shell (`<audio autoplay loop>` in the Alarm Event renderer) and the future Android shell (native `MediaPlayer` via the Capacitor plugin, slice 10).

License policy: each tone must be CC0 / public-domain / commercially-clearable. This `sources.md` is the authoritative license record — no tone ships without a row here, mirroring ADR 0009's "no file ships without a license record" rule.

## Provenance

All five tones are self-synthesized sine waves — explicitly listed in ADR 0009 Decision A as one of the allowed source categories ("self-synthesized sine/sawtooth envelopes"). The script (`scripts/gen-alarm-tones.ts`) is the only producer; it uses `@breezystack/lamejs` (an active fork of `lamejs`) solely to encode raw `Int16Array` samples into mp3 bytes — no third-party audio input, no third-party source audio.

The bytes are committed (not regenerated at build time) so release builds never depend on installing `@breezystack/lamejs` at build time; that package is a root `devDependency` only.

## Replacing these tones later

If a future slice or release wants to ship real CC0/public-domain recordings (e.g. Freesound CC0 packs, Zimmer/Sthagen tone generator output) in place of these self-synthesized tones:

1. Drop the new `.mp3` files into `src/assets/alarm-sounds/` overwriting `tone1..tone5.mp3`.
2. Update this `sources.md` row entry to record the new source URL / project + license.
3. Do NOT delete rows above; append a "Replaced at slice X" note so the historical record survives audit.
